# src/routes — TanStack Start file-based routing

Every `.tsx` file in this folder IS a route. The filename is the URL.

| File             | URL                                                      |
| ---------------- | -------------------------------------------------------- |
| `index.tsx`      | `/`                                                      |
| `about.tsx`      | `/about`                                                 |
| `blog/index.tsx` | `/blog`                                                  |
| `blog/$slug.tsx` | `/blog/:slug` — dynamic segments use `$`, never brackets |
| `__root.tsx`     | layout shell around every page — keep its `<Outlet />`   |

## Hard rules

- This is NOT Next.js or Remix. Never create `src/pages/`, `app/layout.tsx`,
  `app/page.tsx`, or bracket segments like `[id].tsx` — they will not route.
- The root layout is `__root.tsx` and only `__root.tsx`.
- `src/routeTree.gen.ts` is GENERATED by the router plugin on dev/build.
  Never edit it by hand — it regenerates from the files in this folder.
- A new page is just a new file here plus a `<Link>` to it. There is no
  route registry to update.
